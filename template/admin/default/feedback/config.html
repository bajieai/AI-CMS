    中心网关（可选）
    未配置网关时，反馈仅保存在本站数据库中，不对外发送任何数据；配置后提交将自动上报并记录受理编号。
    留空表示不启用；仅支持 http/https，保存时自动去掉末尾斜杠。
    邮件通知（可选）
    依赖「系统设置 → 邮件配置」中已启用的 SMTP 通道。
    上报协议

    POST {网关地址}/api/feedback

    Header: Authorization: Bearer {令牌}

    Body（JSON）：站点地址、程序版本、反馈类型、标题、描述、联系方式、环境信息、提交时间

    返回：{"code":0,"data":{"ticket_no":"..."}}

    本地留存
    所有反馈都会先写入本站 feedback 表；上报失败不影响提交，可在列表页点「重试」再次上报。
